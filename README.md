## Internship Offer Acceptance Predictor

An end-to-end machine learning web application that predicts whether a student will accept an internship offer.

### Features
- Logistic Regression with class balancing
- ColumnTransformer + Pipeline to prevent data leakage
- Streamlit-based interactive UI
- Real-time probability-based prediction

### Tech Stack
- Python
- Scikit-learn
- Pandas
- Streamlit
